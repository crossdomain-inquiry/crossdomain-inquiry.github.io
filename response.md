# Response route

A contribution can be brief and one-time. No account-level identity, particular vocabulary, or continuing commitment is required by the inquiry itself.

Use the repository issue form to return a contribution:

https://github.com/crossdomain-inquiry/crossdomain-inquiry.github.io/issues/new

If a contribution suggests that another exchange may be useful, that can be discussed separately. Continued participation is not presumed from a single response.
